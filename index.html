INSTALLATION

Build & setup

Installing the GTA V Switch port

This walks you through turning a legally-owned GTA V PC install into an NSP you can put on your Switch, from the first download to the first boot. Read a step fully before doing it; most install problems come from skipping the cleanup steps.

What you'll need Grab all of these before you start

Before you start

Have your own copy of the GTA V Legacy PC game files saved somewhere. The patcher edits a copy of these files; it doesn't download the game for you.

1 · Build the installable NSP

  1. Extract build-9b485eb8.7z somewhere, then open NPSDRepackGUI.exe.

  2. Click Browse, go into the extracted build-9b485eb8 folder, and select the game_nx_master.nspd folder.

  3. With game_nx_master.nspd selected, press Start repack.

  4. When it finishes you'll get an outputs folder containing your NSP. Use the app's Open output folder button to jump straight there.

    outputs\build-9b485eb8-game_nx_master.nspd-20260909_143107\nsp\0100b00b51230000.nsp

2 · Patch your game files

  1. Extract gtav-patcher-4.00.7z, open the win-x64 folder, and launch GTAVPatcher.exe.

  2. Next to GTA V folder, browse to the GTA V install you want to patch.

  3. Next to Platform pack, select the build-9b485eb8\platformpack folder.

  4. Set DLC packs to Minimum and make sure Delete high-detail (+hi) resources is checked.

  5. Click Patch and let it run.

Takes about 30 minutes

Let the patcher run to completion; closing it early leaves you with a half-patched folder you'll need to redo from scratch.

Clean up the patched folder

Once patching finishes, open your patched GTA V folder and delete every .dll and .exe file except GTA5.exe, along with anything Rockstar-related. You should be left with exactly this:

switch/ folder update/ folder switch(letter).rpf files .txt files

Trim the DLC packs

Open the following folder and remove DLCs down to the 8 that boot reliably. This is the single most common crash cause; don't skip it.

GTA5\update\switch\dlcpacks

mpbiker mpheist mpchristmas2 mppatchesng patchday1ng patchday2bng patchday2ng patchday3ng
Want more content later?

Don't delete the other DLC folders outright if you can help it; cut and paste them somewhere safe instead. The tab covers which extra packs are safe to add back in, and how.

3 · Install it on your Switch

  1. Copy your .nsp anywhere onto your SD card and install it with Awoo Installer or DBi.

  2. On the SD card, create the folder path:

    atmosphere\contents\0100b00b51230000\romfs

  3. From your patched GTA V folder, copy everything inside its romfs folder into the one you just made on the SD card.

That's the install done

Launch the game from your Switch's home menu. If it boots to the title screen, you're set.

MAINTENANCE UPDATE PATHS

Keeping it current

Updating the game

What you need to redo depends entirely on what the new patch actually touched. Check which case you're in before you start deleting things.

Case 1 - Only gameconfig.xml changed

This is the lightest update. You only need the GTA5SwitchGCUpdater tool.

  1. Open the updater. Next to Select gameconfig.xml, browse to the new gameconfig file from the update.

  2. Next to Select update.rpf file, browse to the update.rpf inside your patched GTA V folder's update directory.

  3. Press Update RPF and choose where to save the result.

  4. Copy the new file over the one on your SD Card and replace the existing one in this folder (never change the name of the update.rpf file):

    SWITCH SD\atmosphere\contents\0100b00b51230000\romfs\update\

Case 2 - The platform pack changed

Repeat the from the Installing tab, but you can skip the DLC deletion and the file cleanup; that part doesn't need to be redone for a platform pack update; unless you're repatching the entire game again.

For a major update

If the update is a big one, you'll get the most reliable result by starting over completely: fresh GTA V Legacy PC files, and the full setup from the Installing tab, rather than patching on top of what's already there.

OPTIONAL CONTENT COMPATIBILITY

Controlled additions

Adding more DLCs safely

The base install strips almost every DLC down to 8 so the game boots reliably. Plenty of other packs are known to work fine; you just add them back deliberately, one at a time, instead of restoring everything at once.

DLCs confirmed to work

These have been tested on top of the 8 required packs without crashing:

mpassault mpchristmas2018 mpgunrunning mpsecurity mpheist3 mpheist4 mpluxe mpluxe2 mplowrider mplowrider2 mpexecutive mpbattle
Stick to this list

Packs not listed here haven't been confirmed. Adding an untested one is the most likely way to bring the crashing back; try it on a spare SD card or back up your saves first.

If you haven't installed yet: keep them or toss them

Back on the trimming step in Installing, you had two options for the DLCs you removed:

Option 1 - Delete them

Simpler. Works great if you only care about the 8 required packs and don't plan on adding more later.

Option 2 - Cut and paste them elsewhere

Keeps every original DLC folder sitting in a spare directory on your PC, ready to copy back in whenever you want more content added. (Like more Vehicles & Mods, Weapons, PEDs, Locations, and Clothing)

Adding a pack back in

Where you add it depends on whether you've already built your NSP.

Haven't installed yet

  1. Before repacking, copy the DLC folder (e.g. mpluxe) from wherever you saved it into:

    GTA5\update\switch\dlcpacks

  2. Continue with the rest of the install as normal; the pack will be baked into your NSP.

Already installed and playing

  1. The Switch reads these DLC folders directly off the SD card, so you don't need to rebuild the NSP. Copy the DLC folder straight into:

    atmosphere\contents\0100b00b51230000\romfs\update\switch\dlcpacks

  2. Launch the game and confirm it still boots before adding a second pack.

Add one at a time

Drop in a single new pack, boot the game, and confirm it's stable before adding the next one. If something you added does cause a crash, removing that one folder again is all it takes to get back to a working state.
